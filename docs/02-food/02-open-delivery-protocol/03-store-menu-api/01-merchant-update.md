## Merchant Update

Send a request to update all store and menu information.
The availability-by-hour feature is restricted to ItemOffer and Options objects. Other categories do not support this granularity


### Basic Information

| **Name** | **Description** |
| --- | --- |
| **URL** |  `https://openapi.99food.com/v4/opendelivery/v1/merchantUpdate` |
| **Method** | POST |
| **Authorization** | OAuth2 |
| **Permission** | Available |


### Request

#### Request Body Parameters

| **Name** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| `merchantStatus` | String | No | Enum: `AVAILABLE`, `UNAVAILABLE`. Indicates if the Merchant is Available or Unavailable. Only use this when you must close (disable) the merchant due to an unexpected event and you don't know when the service will be re-established (e.g. do not use for holidays). |
| `entityType` | String | No | The entity type of the updated object. (e.g., `MERCHANT`, `BASIC_INFO`, `SERVICE`, `MENU`, `CATEGORY`, `ITEM`, `ITEM_OFFER`, `OPTION_GROUP`, `AVAILABILITY`) |
| `updatedObjects` | Array | No | Updated Merchant entity objects |

> * **entityType = "MERCHANT"**

| **Name** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| `id` | String | Yes | Unique identifier. Identifies the merchant in the different systems that the merchant will communicate. This id must be generated by the merchant's Software Service. To avoid duplicates between different merchants it is recommended that the software creates the merchantId using the merchant document (e.g. tax ID) + UUID. If this is not possible, use a UUID. |
| `status` | String | Yes | Enum: `AVAILABLE`, `UNAVAILABLE`. Indicates if the Merchant is Available or Unavailable. Only use this when you must close (disable) the merchant due to an unexpected event and you don't know when the service will be re-established (e.g. do not use for holidays). |
| `basicInfo` | Object | Yes | Describes basic info of a merchant. |
| `service` | Array | Yes | Describes food ordering services details for a merchant. |
| `menus` | Array | Yes | Describes an array of menus. |
| `categories` | Array | Yes | Describes an array of sections in the menu where ItemOffers will be showed. |
| `itemOffers` | Array | Yes | Describes an array of offers for the Items. |
| `items` | Array | Yes | Describes an array of items. To be used with an ItemOffer or an Option. |
| `optionGroups` | Array | No | Describes additional options of an ItemOffer. |
| `availabilities` | Array | No | Array of objects (Availability). Describes the time period during which a Category or an ItemOffer entity is served. |

> * **entityType = "BASIC_INFO"**

| **Name** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| `name` | String | Yes | Merchant Public Name. |
| `averagePreparationTime` | Number | Yes | Average amount of time preparing an order takes, in minutes. |
| `merchantCategories` | Array | Yes | Merchant Categories. |
| `address` | Object | Yes | Merchant Address. |
| `address.street` | String | Yes | Street Name. |
| `address.latitude` | Number | Yes | Latitude in degrees. Values are restricted to the range [[-90, 90]]. |
| `address.longitude` | Number | Yes | Longitude in degrees. Values are restricted to the range [[-180, 180]]. |
| `contactPhones` | Object | Yes | Merchant Contact Phones. |
| `contactPhones.commercialNumber` | String | Yes | Telephone number of the merchant. |
| `logoImage` | Object | Yes | Image to be used as the merchant logo. |
| `logoImage.URL` | String | Yes | URL pointing to an image of the merchant logo. Image requirements: Hosted on a secure connection (SSL). File size must be less than 10MB. Image must be in JPEG, PNG, GIF or WEBP format. Both width and height must be between 320px and 1144px. |
| `bannerImage` | Object | No | Image to be used as the merchant banner (the banner display depends on the client application interface). |
| `bannerImage.URL` | String | Yes | URL pointing to an image of the merchant logo.Image requirements:Hosted on a secure connection (SSL).File size must be less than 10MB.Image must be in JPEG, PNG, GIF or WEBP format.Both width and height must be between 320px and 1144px.It is expected that the images referenced in the URL are downloaded from the server that is making the request, because the URL may no longer be valid after a period of time. |
