## Tracking Event Webhook

This webhook notifies the merchant's Software Service (or the Ordering Application) when a new logistic event occurs (e.g., driver arrived, order picked up).

> **Retry Policy:** The receiver **must** respond with **HTTP 200 OK** (and an empty body) to acknowledge receipt. If any other status code (or timeout) occurs, the Logistic Service will attempt to resend the notification according to its retry policy.

### Request

#### Header Parameters

These headers are sent by the Logistic Service to verify the authenticity of the request.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `X-App-Id` | String | Yes | Unique identifier for the Logistic Service. |
| `X-App-MerchantId` | String | Yes | Unique identifier for the merchant. |
| `X-App-Signature` | String | Yes | SHA256 signature of the request body, using the client secret as the key. |

#### Request Body Parameters

The payload contains the specific details of the logistic update.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `deliveryId` | String | Yes | Delivery ID generated by the Logistics Service. |
| `orderId` | String | Yes | Order ID generated by the Ordering Application. |
| `merchant` | Object | Yes | Merchant identification details. |
| `merchant.id` | String  | Yes | Unique identifier for the merchant. |
| `merchant.name` | String | Yes | Merchant's public name. |
| `event` | Object | Yes | Object containing the status update. |
| `event.type` | String | Yes | The specific logistic event. **Examples:**  `PICKED_UP`, `DELIVERED`, `CANCELLED`. |
| `event.message` | String | No | Free-form message providing additional context (e.g., "Driver waiting at reception"). |
| `event.datetime` | String | Yes | Date and time when the event occurred. **Format:**  `2023-10-27T10:00:00Z` |

#### Request Example

```json
{
  "deliveryId": "delivery-uuid-9876",
  "orderId": "order-uuid-1234",
  "merchant": {
    "id": "merchant-uuid-5555",
    "name": "Company"
  },
  "event": {
    "type": "READY_FOR_PICKUP",
    "message": "Driver has collected the package.",
    "datetime": "2023-10-27T10:30:00Z"
  }
}

```

### Response

#### Response Status Codes

Your system is expected to return the following HTTP status codes.

| **Code** | **Meaning** | **Description** |
| :--- | :--- | :--- |
| `204` | **Success** | Data was received successfully. No response content. |
| `400` | **Bad Request** | Invalid syntax or missing parameters. |
| `403` | **Forbidden** | Authenticated participant request that violates some authorization rule. |
| `404` | **Not Found** | The requested resource was not found. |
| `503` | **Service Unavailable** | Service is not currently available. Requested service may be under maintenance or outside the operating window. |

#### Error Response Parameters

Includes validation errors or server failures.

| **Name** | **Type** | **Description** |
| :--- | :--- | :--- |
| `title` | String | Short description of the problem. |
| `status` | Integer | HTTP code of the returned status (e.g., 400, 500). |
