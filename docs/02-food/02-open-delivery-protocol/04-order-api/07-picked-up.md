## Picked Up 

This endpoint informs that the order has been picked up. This action only applies to orders under `TAKEOUT` mode, and once called, the order status will be updated to Completed.

### Basic Information

| **Item** | **Value** |
| :--- | :--- |
| **URL** | `https://openapi.99food.com/v4/opendelivery/v1/orders/{orderId}/pickedUp` |
| **Method** | `POST` |
| **Permission** | Available |

### Request

#### Path Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `orderId` | String | Yes | The unique identifier of the order generated by the Ordering Application. |
