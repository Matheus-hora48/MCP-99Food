## Order Confirm

This endpoint allows the merchant (or Software Service) to accept an order. By calling this endpoint, you confirm that the restaurant has received the order and will begin preparation shortly.

> **Workflow Note:** Upon successful execution, the order status transitions to `CONFIRMED`, and a corresponding event is triggered in the webhook/polling stream.

### Basic Information

| **Item** | **Value** |
| :--- | :--- |
| **URL** |  `https://openapi.99food.com/v4/opendelivery/v1/orders/{orderId}/confirm` |
| **Method** | `POST` |
| **Permission** | Available |

### Request

#### Path Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `orderId` | string | Yes | The unique identifier of the order generated by the Ordering Application. |

#### Request Body Parameters

The request body must be in `application/json` format.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `createdAt` | String | Yes | Order creation date and time to validate synchronization. **Format:** `2023-10-27T10:00:00Z` |
| `orderExternalCode` | String | Yes | External order code used by the merchant or marketplace for reconciliation. |
| `reason` | String | No | Free text field for internal notes about the confirmation (e.g., "Accepted by Manager John"). |

#### Request Example

```json
{
  "createdAt": "2023-10-27T18:30:00Z",
  "orderExternalCode": "POS-12345-AB",
  "reason": "Accepted by Kitchen Staff"
}

```
