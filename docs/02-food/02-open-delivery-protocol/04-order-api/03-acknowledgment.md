## Acknowledgment 

This endpoint allows you to acknowledge a list of events simultaneously via the request body. This is useful for processing batches of events retrieved from the polling endpoint.

### Basic Information

| **Item** | **Value** |
| :--- | :--- |
| **URL** |  `https://openapi.99food.com/v4/opendelivery/v1/events/acknowledgment` |
| **Method** | `POST` |
| **Authorization** | OAuth2 |

### Request

#### Request Body Parameters

The body must contain an **Array** of event objects.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `id` | String | Yes | A unique identifier of the event. |
| `orderId` | String | Yes | The unique identifier of the order generated by the Ordering Application. |
| `eventType` | String | Yes | The type of the event being acknowledged. **Enum Values:** • `CREATED` • `CONFIRMED` • `READY_FOR_PICKUP` •`DISPATCHED` • `DELIVERED` • `CONCLUDED` • `CANCELLATION_REQUESTED` • `CANCELLATION_REQUEST_DENIED` • `CANCELLED` • `ORDER_CANCELLATION_REQUEST` • `CANCELLED_DENIED` |

#### Request Example

```json

    {
    "id": "c4b8b6f7-1234-4a5b-b987-654321abcdef",
    "orderId": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
    "eventType": "CREATED"
    }
    
```
