## Get Order Details

This endpoint retrieves full details of a specific order.

### Basic Information

| **Item** | **Value** |
| :--- | :--- |
| **URL** |  `https://openapi.99food.com/v4/opendelivery/v1/orders/{orderId}` |
| **Method** | `GET` |
| **Authorization** | OAuth2 |
| **Permission** | Available |

### Request

#### Path Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `orderId` | string | **Yes** | The unique identifier of the order. |

### Response 

#### Response Status Codes

| **Code** | **Meaning** | **Description** |
| :--- | :--- | :--- |
| `200` | **Success** | Order returning success. |
| `400` | **Bad Request** | Invalid syntax or missing parameters. |
| `401` | **Unauthorized** | Request lacks valid authentication credentials for the target resource |
| `403` | **Forbidden** | Authenticated participant request that violates some authorization rule. |
| `404` | **Not Found** | The requested resource was not found. |
| `503` | **Service Unavailable** | Service is not currently available. Requested service may be under maintenance or outside the operating window. |

#### Success Response Parameters

The response is a JSON object organized into the following logical sections.

General information about the order structure.

| **Name** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| `id` | String | Yes | Unique identifier generated by the Ordering Application. |
| `displayId` | String | Yes | Short ID shown to the customer in the app interface. |
| `type` | String | Yes | Type of delivery. **Value:** `DELIVERY` (for orders delivered to the customer's address), `TAKEOUT` (orders that will be picked up at the establishment by the customer). |
| `sourceAppId` | String | No | Source application ID. Default: `99food`. |
| `createdAt` | String | Yes | Order creation date/time. |
| `orderTiming` | String | Yes |Timing for initiating the order. **Enum:** `INSTANT` (must be prepared immediately). |
| `preparationStartDateTime` | String \<date-time> | Yes | Suggestion for preparation start time (usually same as creation time). |
| `merchant` | Object | Yes | Merchant information. (See **Section 1** below) |
| `items` | Array | Yes | Array of order items. (See **Section 2**) |
| `otherFees` | Array | No | Other fees that may apply (e.g., Tips). (See **Section 3.1**) |
| `discounts` | Array | No | Any discounts that may apply. (See **Section 3.2**) |
| `total` | Object | Yes | Financial sum of the order values. (See **Section 3.3**) |
| `payments` | Object | Yes | Payment methods and status. (See **Section 3.4**) |
| `customer` | Object | Conditional| **Required** if `type` is `DELIVERY`. (See **Section 4**) |
| `delivery` | Object | Conditional| **Required** if `type` is `DELIVERY`. (See **Section 5**) |
| `takeout` | Object | Conditional| **Required** if `type` is `TAKEOUT`. (See **Section 6**) |
| `extraInfo` | String | No | Extra information field. Currently used to carry auxiliary information that does not have a dedicated field in this schema, such as: the virtual phone number extension (`localizador`), whether the customer requires cutlery (`precisa de talheres`), and the pickup confirmation code for self-pickup orders (`código de retirada`). When present, multiple pieces of information are concatenated in this field, separated by semicolons (`;`). **Example:** `"localizador: 12345678; código de retirada: 6795; precisa de talheres: sim"` | |

**Section 1. `merchant`**

Identifies the store associated with the order.

| **Name** | **Type** | **Required** | **Description** |
| --- | --- | --- | --- |
| `id` | String | Yes | Unique Merchant Identifier used across systems. |
| `name` | String | Yes | Merchant Public Name. |

**Section 2. `items`**

List of products contained in the order.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `id` | String | Yes | Unique identifier of the item. |
| `index` | Integer | No | Item's position in the list. |
| `name` | String | Yes | Product name. |
| `unit` | String | Yes | Unit type. **Fixed:** `UN`. |
| `quantity` | Number | Yes | Amount of items. |
| `unitPrice` | Object | Yes | Price per unit paid by the customer. (See **Section 3.5 Price Object**) |
| `originalPrice` | Object | No | Original price (informational only, before markdowns). (See **Section 3.5 Price Object**) |
| `totalPrice` | Object | Yes | Total price of the item line (`quantity * (unitPrice + optionsPrice)`). (See **Section 3.5 Price Object**) |
| `options` | Array | No | List of selected sub-items/modifiers. (See structure below) |

> * **Item Options (`items.options`)**

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `id` | String | Yes | Unique identifier of the option. |
| `index` | Integer | No | Option's position. |
| `name` | String | Yes | Option name. |
| `unit` | String | Yes | Unit type. **Fixed:** `UN`. |
| `quantity` | Number | Yes | Quantity of this option. |
| `unitPrice` | Object | Yes | Price per unit. |
| `totalPrice` | Object | Yes | Total price (`quantity * unitPrice`). |

**Section 3. Fees & Discounts** 

This section defines the additional charges and price reductions, including detailed sponsorship breakdowns.

> * **3.1 Other Fees (`otherFees`)**

List of extra charges applied to the order.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `type` | String | Yes | **Enum:** `DELIVERY_FEE`, `SERVICE_FEE`, `TIP`. |
| `receivedBy` | String | No | **Enum:** `MARKETPLACE`, `MERCHANT`, `LOGISTIC_SERVICES`. |
| `price` | Object | Yes | The fee price. Including service fees, tip money, delivery fee. (See **Section 3.5 Price Object**) |

> * **3.2 Discounts (`discounts`)**

List of discounts applied. **Note:** The sum of `sponsorshipValues` must match the `amount`.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `amount` | Object | Yes | Total value of the discount. (See **Section 3.5 Price Object**) |
| `target` | String | Yes | **Enum:** `CART`, `DELIVERY_FEE`, `ITEM`. |
| `targetId` | String | No | Mandatory only if `target` = `ITEM`. |
| `sponsorshipValues` | Array | Yes | Breakdown of who is paying for the discount. (See structure below) |

> Discounts Sponsorship (`discounts.sponsorshipValues`)

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `name` | String | Yes | **Enum:** `MARKETPLACE`, `MERCHANT`, `CHAIN`. |
| `amount` | Object | Yes | Discount amount given by this sponsor. (See **Section 3.5 Price Object**) |

> * **3.3 Total Fees (`total`)**

Financial summary of the order.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :--- | :--- |
| `itemsPrice` | Object | Yes | Sum of all items. (See **Section 3.5 Price Object**) |
| `otherFees` | Object | Yes | Sum of other fees (Delivery, Service, Tip). (See **Section 3.5 Price Object**) |
| `discount` | Object | Yes | Sum of all discounts. (See **Section 3.5 Price Object**) |
| `orderAmount` | Object | Yes | **Final Order Value** (`itemsPrice + otherFees - discount`). (See **Section 3.5 Price Object**) |

> * **3.4 Payment Details (`payments`)** 

Payment details and methods.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :--- | :--- |
| `pending` | Number | Yes | Amount still to be paid. |
| `methods` | Array | Yes | List of payment methods used. |
| `methods.value` | Number | Yes | Amount paid by this specific method. |
| `methods.currency` | String | Yes | The 3-letter ISO 4217 currency code. |
| `methods.type` | String | Yes | **Enum:** `PREPAID`, `PENDING`. |
| `methods.method` | String | Yes | **Enum:** `CREDIT`, `DEBIT`, `MEAL_VOUCHER`, `FOOD_VOUCHER`, `DIGITAL_WALLET`, `PIX`, `CASH`, `OTHER`, etc. |
| `methods.brand` | String | No | Card brand (e.g., `VISA`, `MASTERCARD`, `ELO`, `VR_BENEFICIOS`). |
| `methods.changeFor` | Number | No | **(Cash only)** Total amount the customer will hand over (for change calculation). |
| `methods.methodInfo` | String | No | Additional info (e.g., wallet name, auth number). |

> * **3.5 Price Object** 

This common structure is used for all monetary values throughout the Order response to ensure consistency.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `value` | Number | Yes | Price value. Up to 4 decimal places are accepted (e.g., `10.50` or `10.5000`). |
| `currency` | String | Yes | The 3-letter ISO 4217 currency code (e.g., `BRL`, `MXN`, `USD`). |

**Section 4. `customer`**

Details about the consumer. **Required** if `type` is `DELIVERY`.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :--- | :--- |
| `id` | String | Yes | Unique identifier (generated by Ordering App if unknown). |
| `name` | String | Yes | Customer's name. |
| `phone` | Object | Yes | Customer's real phone, masked phone, or call center number for contact. |
| `ordersCountOnMerchant` | Number | Yes | Total past orders placed by this customer at this merchant. |

**Section 5. `delivery`**

Logistics information. **Required** if `type` is `DELIVERY`.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `deliveredBy` | String | Yes | Indicates who is responsible for the logistics. **Enum:** `MERCHANT`, `MARKETPLACE`. |
| `estimatedDeliveryDateTime` | String | Yes | Estimated arrival date/time shown to the customer in the app interface. |
| `deliveryAddress` | Object | Yes | The physical location for delivery. (See structure below) |
| `pickupCode` | String | No | A 4-digit verification code generated upon order creation, used by the store and the courier for meal handover confirmation under platform delivery mode. |

> * **Delivery Address (`delivery.deliveryAddress`)** 

Detailed address information and geographic coordinates.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `country` | String | Yes | Two-letter **ISO 3166-1 alpha-2** country code (e.g., `BR`). |
| `state` | String | Yes | State or region code (ISO 3166-2 recommended). |
| `city` | String | Yes | City name. |
| `district` | String | Yes | Neighborhood or District name. |
| `street` | String | Yes | Street name. |
| `number` | String | Yes | Street number. |
| `complement` | String | No | Address complement (e.g., Apt, Suite, Building). |
| `reference` | String | No | Landmark or additional reference instructions. |
| `formattedAddress` | String | Yes | The complete, formatted address string suitable for display. |
| `postalCode` | String | Yes | Postal or Zip Code. |
| `coordinates` | Object | Yes | Geographic coordinates of the delivery location. |
| `coordinates.latitude` | Number | Yes | Latitude in degrees. Range: `[-90, 90]`. |
| `coordinates.longitude` | Number | Yes | Longitude in degrees. Range: `[-180, 180]`. |

**Section 6. `takeout`**

Information for `TAKEOUT` orders. **Required** if `type` is `TAKEOUT`.

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `mode` | String | Yes | **Enum:** `DEFAULT`|
| `takeoutDateTime` | String | Yes | The same time as order creation time. |
