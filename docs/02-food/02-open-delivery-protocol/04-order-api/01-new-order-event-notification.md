## New Order Event Notification

This webhook notifies the system about a new event related to an order. It is triggered by the Ordering Application and provides essential information for event processing and order tracking.

### Request

#### Header Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `X-App-Id` | String | Yes | Unique identifier for the Ordering Application. Must be consistent across all Software Services implementing this webhook. |
| `X-App-MerchantId` | String | Yes | Unique identifier for the merchant across different systems. |
| `X-App-Signature` | String | Yes | SHA256 HMAC of the request body, using the client secret as the key. |

#### Request Body Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `eventId` | String | Yes | Unique identifier for the event. |
| `eventType` | String | Yes | Type of event: • `CREATED` • `CONFIRMED`  • `READY_FOR_PICKUP`  • `DISPATCHED` • `DELIVERED` • `CONCLUDED` • `CANCELLATION_REQUESTED` • `CANCELLATION_REQUEST_DENIED` • `CANCELLED` • `ORDER_CANCELLATION_REQUEST` • `CANCELLED_DENIED` |
| `orderId` | String | Yes | Unique identifier for the order, generated by the Ordering Application. |
| `orderURL` | String | Yes | URL to retrieve order details. |
| `createdAt` | String | Yes | Date and time when the order was created. |
| `sourceAppId` | String | No | Source application ID. Default: `99food` |


### Response

#### Response Status Codes

| **Code** | **Meaning** | **Description** |
| :--- | :--- | :--- |
| `200` | **Success** | Status 200 available for compatibility reasons. Please use status 204 instead. |
| `204` | **Success** | Data was received successfully. No response content. |
| `400` | **Bad Request** | Invalid syntax or missing parameters. |
| `403` | **Forbidden** | Authenticated participant request that violates some authorization rule. |
| `404` | **Not Found** | The requested resource was not found. |
| `503` | **Service Unavailable** | Service is not currently available. Requested service may be under maintenance or outside the operating window. |

#### Error Response Parameters

| **Name** | **Type** | **Required** | **Description** |
| :--- | :--- | :--- | :--- |
| `title` | String | Yes | Short description of the problem. |
| `status` | Integer | Yes | HTTP code of the returned status (e.g., 400, 500). |
