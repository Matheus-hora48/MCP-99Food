## Adjust Order Items

the merchant should use this endpoint  to adjust the order items


### Basic Information

| **Name** | **Description** |
| --- | --- |
| `URL` | [https://openapi.99food.com/v3/order/operate/adjustItem](https://openapi.99food.com/v3/order/operate/adjustItem) |
| `Method` | POST |
| `Permission` | Available |


### Request Path Parameters

| **Name** | **Type** | **Required** | **Description** | **Example** |
| --- | --- | --- | --- | --- |
 | `Authorization`  | http header  | Yes  | Access/Auth Token  | eyJhbGciOiJIUzI1NiIsInR5cC |
 | `order_id`  | int  | Yes  | order id  | 5764631035788520000  |
 | `cancel.items[].app_item_id`  | string  | No  | item id provided by the partner  | wHrrj9t9UBFq|2273  |
 | `cancel.items[].mdu_id`  | string  | No  | id generated by DiDiFood, alongside app_item_id in order detail  | ABE92739AE7D9D28E4F7E47B3499DFBE_2  |
 | `cancel.items[].cancel_amount`  | int  | No  | amount of items to be cancelled  | 3  |
 | `soldout.items[].app_item_id`  | string  | No  | item id provided by the partner  | wHrrj9t9UBFq|2273  |
 | `soldout.items[].sold_out_type`  | enum  | No  | 1: sold out before the end of the day  2: sold out permanently| 1  |
 | `adjust.items[].app_item_id`  | string  | No  | item id provided by the partner  | wHrrj9t9UBFq|2273  |
 | `adjust.items[].mdu_id`  | string  | No  | id generated by DiDiFood, alongside app_item_id in order detail  | ABE92739AE7D9D28E4F7E47B3499DFBE_2  |
 | `adjust.items[].weight_total_previous`  | int  | No  | previous item weight  | 800  |
 | `adjust.items[].weight_total_new`  | int  | No  | new item weight  | 900  |
 | `adjust.items[].weight_unit`  | string  | No  | weight unit, and only gram is supported currently  | gram  |

*[cancel.items], [soldout.items], [adjust.items] are independent participants. For each type, the parameters inside the structure are generally required. If cancel is required, all parameters in cancel must be filled in.
