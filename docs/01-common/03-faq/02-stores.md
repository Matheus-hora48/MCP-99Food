## Stores

### Terminology and Meanings

**1. What is the meaning of each value of `auto_switch`?**
There are 3 possible values:
- Set store online automatically.
- Set store offline automatically.
- Set store both online and offline automatically (we recommend using in all stores). 
For complete documentation, please refer to **Store API > Set Store Status.**

**2. What does type in shop_phone means?**
- 0: Mobile phone (_default_)
- 1: Landline


### Binding Stores

**1. How to connect shop_id with the id in my POS system?**
We provide multiple methods to bind stores between 99Food and your POS system. These methods are explained in the **Introduction Guide > Basic Process Overview**, in the **Phase 4: Expansion and Monitoring** section.


### Store Operation

**1. Does PC web version of the app support opening stores?**
No, we recommend downloading the app (Windows or Android) for store operations.
